# Data Visualization Dashboard

## Project Overview
This is a Data Visualization Dashboard built using *Python and Streamlit*.  
It allows users to explore sales data through different graphs such as line Graphs, Bar Graph, Pie charts, and Scatter plots.

## Technologies Used
- Python  
- Streamlit  
- Pandas  
- Matplotlib  

## How to Run
1. Install the dependencies:  
   ```bash
   pip install -r requirements.txt
2. Run The App Using streamlit:
    streamlit run app.py

## Features:
1. Interactive Line Graphs
2. Pie and Bar Charts for category-wise analysis
3. Scatter Plot for data analysis
4. User-friendly filters
